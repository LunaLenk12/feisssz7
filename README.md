# feisssz7.mn

Bio-link page in Next.js 14 (App Router) + Tailwind.

```bash
npm install
npm run dev     # http://localhost:3000
```

- Edit name, bio lines and links in `lib/profile.ts`
- Drop your background clip at `public/bg.mp4` (plays with sound after the "click to enter" screen)
- Drop your avatar at `public/avatar.png`
- Deploy to Vercel, then add the `feisssz7.mn` domain in the project settings
